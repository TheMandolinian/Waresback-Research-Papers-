## Current Paper

### Economic Security Valuation of Institutional Distributed Ledger Networks

**Subtitle:** A Framework for Evaluating Digital Infrastructure Beyond Transaction Utility  
**Author:** James Bradley Waresback  
**Draft Version:** 0.1  
**Draft Date:** June 2026  
**Status:** Public research draft

This paper proposes a framework for evaluating institutional distributed ledger networks through economic security, utility equilibrium, security equilibrium, strategic reserve demand, treasury transition, fixed-fee decoupling, and institutional confidence thresholds.

Hedera / HBAR is used as the primary case study, but the framework is intended to apply beyond HBAR.
