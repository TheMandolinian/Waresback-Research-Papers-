### 1. Economic Security Valuation of Institutional Distributed Ledger Networks

A framework for evaluating institutional distributed ledger networks through economic security, utility equilibrium, security equilibrium, strategic reserve demand, treasury transition, fixed-fee decoupling, and institutional confidence thresholds.

- Paper folder: [Economic Security Valuation](papers/economic-security-valuation-dlt/README.md)
- PDF: [economic-security-valuation-dlt-v0.1.pdf](papers/economic-security-valuation-dlt/draft-v0.1/economic-security-valuation-dlt-v0.1.pdf)
- Companion summary: [economic-security-valuation-dlt-v0.1.md](papers/economic-security-valuation-dlt/draft-v0.1/economic-security-valuation-dlt-v0.1.md)

Hedera / HBAR is used as the primary case study, but the framework is intended to apply beyond HBAR.

### 2. HashHelix Whitepaper V1.9.5

HashHelix is a deterministic event sequencing and verification framework. The current public framing is V1.9.5: HashHelix is not a literal time engine, public blockchain, or cryptocurrency by default. It is a framework for deterministic sequence authority, accepted event ordering, canonical payload binding, receipt/readback discipline, replayable projection, and future commitment structures.

- Paper folder: [HashHelix Ledger](papers/hashhelix-ledger/README.md)
- PDF: [hashhelix-whitepaper-v1.9.5.pdf](papers/hashhelix-ledger/draft-v1.9.5/hashhelix-whitepaper-v1.9.5.pdf)
- Companion summary: [hashhelix-whitepaper-v1.9.5.md](papers/hashhelix-ledger/draft-v1.9.5/hashhelix-whitepaper-v1.9.5.md)
- Plain-English supplement: [HashHelix Teachable Doc](papers/hashhelix-ledger/technical-summaries/hashhelix-teachable-doc.md)

Legacy HashHelix material is preserved for historical context only. V1.9.5 is the current corrected public framing.
