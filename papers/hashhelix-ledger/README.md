# HashHelix Ledger

HashHelix is a deterministic event sequencing and verification framework by James Bradley Waresback / The Mandolinian. The current public framing is V1.9.5: HashHelix is not a literal time engine, public blockchain, or cryptocurrency by default. It is a framework for deterministic sequence authority, accepted event ordering, canonical payload binding, receipt/readback discipline, replayable projection, and future commitment structures.

Start with the PDF first, then use the Markdown companion as a short reader guide. Legacy material is preserved for historical context only and should not override V1.9.5 where terminology conflicts.
